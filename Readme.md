### Definition
Instead of just moving the code, and having problem while the application works fine for me but not in the production or a friend device, the containerization is the **concept, methodology and strategy** of packing an application with all its runtime environment including the necessary dependencies, system libraries and configuration files, so the application can runs **uniformly** and **consistently** across any infrastructure.
